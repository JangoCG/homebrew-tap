# Polaris Homebrew Tap

Homebrew tap for [Polaris](https://polaris-deploy.com), the native macOS GUI for Kamal deployments.

## Install

```sh
brew install --cask jangocg/tap/polaris
```

## Upgrade

Polaris updates itself via Sparkle. To upgrade through Homebrew instead:

```sh
brew upgrade --cask polaris
```

## Uninstall

```sh
brew uninstall --cask polaris
```

Add `--zap` to also remove preferences and caches.
